About This Project

COVID-19 Data Analysis & Visualization Platform

A production-level data analytics application designed to analyze real-time COVID-19 trends, testing progress, hotspot regions, and public health indicators using modern data science and visualization technologies.

Project Overview

Transforming Pandemic Data Into Actionable Insights

This project was developed to analyze and visualize large-scale COVID-19 datasets collected from public health sources. The platform enables users to monitor infection rates, mortality trends, diagnostic testing, and country-level pandemic progression using interactive dashboards.

The application emphasizes data storytelling, analytical reporting, and real-time insights to support understanding of pandemic behavior and public health policy outcomes.

Real-time COVID-19 global trend analysis
Country-wise hotspot and testing tracking
Interactive dashboards powered by Chart.js
Data cleaning, feature engineering, and trend visualization workflows

Dataset & Data Source

The application uses the publicly available owid-covid-data (1).csv dataset from Our World in Data, covering global COVID-19 statistics from Dec 2019 to Sep 2020 — including cases, deaths, testing, and socioeconomic indicators.
